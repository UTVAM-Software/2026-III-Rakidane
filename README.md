# 2026-III-Rakidane

## Instalación
1. git clone https://github.com/rraulmenesesg-jpg/2026-III-Rakidane
2. python -m venv venv
3. venv\Scripts\activate   (Linux/Mac: source venv/bin/activate)
4. pip install -r requirements.txt
5. Copiar .env.example a .env y editar los valores
6. python manage.py migrate
7. python manage.py createsuperuser
8. python manage.py runserver
